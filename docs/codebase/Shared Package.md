# Shared Package

**`@travel/shared`** at `packages/shared` — private workspace package consumed as ==raw TS source== (`main`/`types` → `./src/index.ts`, no build step, only dependency `zod`). Imported by both apps as `@shared/*`. Barrel `src/index.ts` re-exports `./types`, `./constants`, `./validators`, `./utils/refund`, `./utils/payout`.

> [!tip] The No-Magic-Strings Rule
> Every domain value (role, status, sort field) lives here. Before adding a string: `grep -r "your-string" packages/shared/src/constants/` — import if found, add here if not. Pattern: readonly tuple (for `z.enum()`) + dot-access object + derived type. See root `CLAUDE.md`.

## Utils

- **`refund.ts`** *(root-exported)* — `calculateRefundPercent(policy, hoursUntilTrip)`, `estimateRefund` → [[Product Domain#Refund Policy Matrix]]. Day-based cliff (`REFUND_CLIFF_DAYS`), deliberately kept in permanent agreement with `payout.ts` at the exact boundary. Tested in `refund.test.ts`.
- **`payout.ts`** *(root-exported — dependency-free, no Prisma/I-O)* — single source of truth for the Cashfree organizer deposit/balance payout split → [[Product Domain#Organizer Deposit / Balance Payout]] and [[Payments & Webhooks]]. `calculatePayoutSplit({ baseAmount, commissionRate, depositPercent?, hoursUntilTrip, cancellationPolicy })` computes `entitlement`/`deposit`/`balance`/`refundWindowClosed` (deriving `refundWindowClosed` from `refund.ts`'s `calculateRefundPercent`, never reimplementing the cliff comparison). `assertPayoutSafe(deposit, platformRetained, refundWindowClosed?)` throws if `deposit > platformRetained` (skipped when `refundWindowClosed`) — the hard backstop against ever needing a clawback from the organizer; callers must Sentry-capture before letting the throw propagate.
- **`slug.ts`** — `generateSlug`, `slugify`, `generateTripSlug(title, startDate)`, `deslugify`.
- **`organizer-docs.ts`** — `getDocCount`, `areDocsComplete` (vs `REQUIRED_DOC_COUNT=3`).
